方案取舍分析

选 A（直连 bank）当：外部 master 只需要加载/校验 TCM（程序装载器场景）——路径最短、不抢核心总线、复位期加载零竞争；代价是访问范围受限、无外部地址转发。

选 B（挂 router）当：外部主机需要操作 timer、访问核外外设或做全簇调试（如另一个 cluster 互访）——通用性强；代价是与 LSU 共享 dmem 仲裁（3 master RR），外部流量大会拖慢核心 load/store。

两者并不互斥：B 的 ext_ahb_slv 可与 A 的 bank 级 sbr 并存（router 级 + bank 级双层入口），但需处理两条路径同时写 TCM 的仲裁归属——当前两边各自只有一条。

scr1_ext_ahb_slv.sv（B，节选）地址解码不下沉复制 · 交给 dmem_router
/// @brief      AHB-Lite SLAVE port - external bus master access to the cluster
///             ITCM / DTCM / timer  - by decoding the address downstream,
///                                    in scr1_dmem_router
///             anything else        - forwarded out of the core's own
///                                    AHB/AXI master port
///             The extra ISSUE state is not a limitation but a requirement: in
///             AHB the write data of a transfer only appears one cycle after its
///             address, so a write can never be issued in the address phase.
scr1_tcm_ahb_sbr.sv（A，节选）地址窗口判定 + busy_r 完成拍防重锁存
// Address decode: combined ITCM+DTCM window (bank split is done in scr1_tcm)
assign tcm_hit = ((haddr & SCR1_TCM_ADDR_MASK) == SCR1_TCM_ADDR_PATTERN);
// busy_r masks the completion cycle: HREADYOUT has just risen but the
// master still drives the OLD HTRANS value - sampling here would
// duplicate the just-finished transfer with already-invalid HWDATA.
assign addr_phase = (fsm == SCR1_SBR_FSM_IDLE) & ~busy_r
                    & (htrans == SCR1_HTRANS_NONSEQ) & hreadyin;
